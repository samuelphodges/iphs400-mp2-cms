# Client brief

Client: Kenyon College Varsity Baseball Team Alumni


The site is run by the head coach Matt Burdette who has some experience with computers. He knows how to work through a website but doesn't know how to create or edit websites. The second editor of the website is named Joe who has the ability to update alumni network and events. The audience for the website is Kenyon players, fans, students, parents, and alumni of the team. They are usually trying to find updates on the team and upcoming schedules and events.
The problem now is that there is no website for just the Kenyon College Baseball Team Alumni. Alumni can only gather minimal information from talking with each other. For this website to be ideal, it would include the current team's schedule, a location within the website for alumni events, and a contact list of alumni. Ideally, alumni can find information on what is going on with the team and contact information much quicker. The contact list entry is opt-in and alumni can choose whether to include their name and email on the list. 
What must never happen is that people besides Matt Burdette and Joe can edit the website. Matt has the power to edit everything, but Joe is unable to edit the current team schedule.
